# Marcela 15 anos — convite online

Site estático (HTML/CSS/JS), publicado na Vercel a partir deste repositório.

## Editar

- **WhatsApp, prazo de confirmação e endereço do mapa:** bloco `CONFIG` no topo de `js/main.js`.
- **Textos:** `index.html`.
- **Música:** coloque o arquivo em `assets/audio/musica.mp3`. Ela começa a tocar quando o convidado toca no envelope; o disco liga e desliga.

## Rodar localmente

```bash
python3 -m http.server 4173
```

Depois abra http://localhost:4173.
